# 5分デモガイド

## 目的

意匠情報を件数だけで終わらせず、企業・分類・物品名・意匠種別の傾向から根拠意匠へ戻れることを5分で示します。公開Previewは架空のサンプルデータだけを使用し、実データは画面共有用のローカル検証に限定します。

## デモ前チェック

- Preview URLを使用し、Productionは開かない・変更しない。
- 初期画面に「サンプルデータ版です」と表示されていることを確認する。
- 実データ、認証情報、ローカルパスをブラウザや資料に表示しない。
- `/api/demo-designs` は未実装のため、保護データ読込ボタンが表示されないことを確認する。
- 実データ配備の状態は `BLOCKED_REAL_DATA_DEPLOY` のままと説明する。

## 進行

### 0:00–0:40 何ができるか

「意匠情報から、市場や企業が注力する領域、変化の兆候、次に検討する材料を把握します。公開版は架空のサンプルデータです。」

### 0:40–1:30 条件を選ぶ

1. 分析対象
2. 見たい領域
3. 対象となる意匠情報
4. 対象期間
5. 分析目的

の順に確認し、プリセットまたは任意条件で「分析を開始」を押します。

### 1:30–2:30 結果の要点

「今回わかったこと」で、対象件数と最初に見る3つの示唆を説明します。件数ボタンから根拠意匠一覧に移れることを見せます。

### 2:30–3:40 ランキングから根拠へ

「任意：データ・デモ・技術情報」を開き、企業別・分類別・物品名別・意匠種別ランキングの件数を1つクリックします。根拠意匠一覧が選択したランキング項目だけに絞られたことを確認します。

### 3:40–4:30 詳細分析から根拠へ

「選択した目的別の詳細分析を見る」を開き、統合された「根拠意匠を見る」ボタンを押します。重複操作なしで根拠一覧に移れることを示します。

### 4:30–5:00 現在地と次フェーズ

「現在はサンプルデータ版とローカル検証版までです。安全な保存先と同一オリジンAPIが未整備のため、実データ配備は `BLOCKED_REAL_DATA_DEPLOY` です。外部データ連携や高度分析は、利用条件とセキュリティを確認した後の別フェーズです。」

## 終了条件

- ランキング件数と詳細分析の双方から根拠意匠一覧へ移動できた。
- 公開版が架空データであることを明示した。
- 実データや認証情報を表示しなかった。
- Previewだけを使用し、Productionを変更しなかった。
