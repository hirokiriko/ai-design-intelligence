# KIRIKO Design Signals プレゼンテーション台本

## 0:00–0:40 目的

「KIRIKO Design Signalsは、意匠情報から、市場・企業・商品化領域の先行シグナルを捉えるためのアプリです。」

「意匠情報を俯瞰し、市場動向、企業動向、商品化領域、デザイン変化の検討材料を整理します。結果から根拠意匠へ戻れるため、傾向と元情報を同じ画面で確認できます。」

「分析結果は将来や企業戦略を断定するものではありません。他の知財情報、商品情報、事業情報等と組み合わせて検討するための参考情報です。今日の公開Previewは、すべて架空のサンプルデータです。」

## 0:40–1:30 条件設定

「最初に推奨プリセットを選びます。画面は1から6まで、表示順とDOM順をそろえています。」

「1は市場全体・特定業界・特定企業から分析対象を選びます。2は見たい領域、3は物品・画像・空間など対象となる意匠情報、4は直近1年または2年、5は市場動向・商品化領域・企業動向・デザイン変化・画像意匠の動向から目的を選びます。意匠情報の種類は目的に合わせて自動設定され、必要なら手動で変更できます。」

「出力部門は初回の必須入力ではありません。通常は詳細設定を開かず、6の『分析を開始』から結果と根拠へ進めます。」

## 1:30–3:00 分析結果

「最初に今回の分析対象意匠数を表示します。その後、注目トレンド、商品化領域のヒント、企業動向、必要に応じた追加分析の順に確認します。」

「表現は断定ではなく、現在のデータと条件で確認できた参考傾向です。根拠がない示唆は表示せず、0件の場合は条件を見直す案内を出します。」

「画面上の件数は操作できます。ここから文章だけで終わらず、その傾向を構成する根拠意匠へ進みます。」

## 3:00–4:10 根拠確認

「この件数をクリックすると、対応する根拠意匠だけに一覧が絞り込まれます。表示件数とクリックした件数が一致していることを確認します。」

「1件を開くと、企業名、物品名または画像の用途、意匠分類、登録番号、出願番号、公報番号、公報発行日、意匠種別、情報源、意匠の説明、取得済みの図面情報を確認できます。」

「取得できていない値は推測して補いません。図面画像本体と外部リンクは未接続です。企業・分類・物品名・意匠種別のランキングも、件数から同じように根拠へ戻れます。」

## 4:10–5:00 展開可能性と現在地

「条件は業界、企業、商品領域、期間、意匠種別に合わせて変更できます。次回は、実際に見たいテーマへ合わせた専用デモを用意できます。」

「現在版は、架空サンプルの公開デモ、Git管理外ローカルJSONの限定検証、ルールベース分析、集計、根拠意匠への遷移、取得済みの公報・図面情報の表示までです。」

「LLMによる高度分析、プレス・IR・Web商品情報、商用データベース、社内情報、図面画像の高度解析、自動監視、実データ配信は将来構想です。実データは公開PreviewやProductionへ配備しておらず、現在の状態は `BLOCKED_REAL_DATA_DEPLOY` です。」

「最後に、見たい分析、現在利用できるデータ、困っている工程を教えてください。次回の専用デモまたはPoCで確認する範囲を一緒に決めます。」
