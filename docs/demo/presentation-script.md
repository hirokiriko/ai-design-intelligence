# プレゼンテーション台本

## 導入

「AI Design Intelligenceは、意匠情報を商品開発や企業戦略の検討材料として読み解くためのデモです。案件や制度によって公表時期は異なるため、他の知財情報や事業情報と合わせて判断します。」

「今日お見せする公開Previewは、すべて架空のサンプルデータです。実在企業や実在公報のデータではありません。」

## 条件設定

「分析条件は画面の1から5まで、表示順に選びます。対象、領域、意匠情報、期間、分析目的です。今回は説明しやすいプリセットを使います。」

「通常のデモでは技術情報を前面に出していません。データ境界や分析方式は、必要な場合だけ詳細設定または注意事項で確認できます。」

## 分析結果

「最初に対象件数と重要な示唆を表示します。ここで大切なのは、文章だけでなく、対応する根拠意匠に戻れることです。」

「示唆の件数を押すと、該当する根拠意匠だけに絞り込まれます。詳細分析カードでも、操作は1つの『根拠意匠を見る』ボタンに統合しています。」

## ランキング

「企業別、分類別、物品名別、意匠種別のランキングを比較できます。件数を押すと、その項目に該当する根拠意匠一覧を表示します。」

「このため、上位傾向を見つけた後、どの意匠が件数を構成しているかを同じ画面で確かめられます。」

## 境界と今後

「現在の公開版は架空サンプル、実データ版はGit管理外のローカルJSONを使う画面共有検証です。実データをGitや公開ビルドへ追加していません。」

「安全な保存先と同一オリジンの `/api/demo-designs` は未実装です。そのため、保護データ読込ボタンは表示せず、実データ配備は `BLOCKED_REAL_DATA_DEPLOY` のままです。」

「外部情報連携、LLMによる高度分析、公報・図面画像や外部リンクは将来候補です。利用条件、著作権、セキュリティ、費用を確認してから別フェーズで判断します。」

## 締め

「本日の確認ポイントは、条件を変えると結果が変わること、ランキングと示唆の双方から根拠意匠へ戻れること、公開版と実データ版の境界が明確であることの3点です。」
